# LLM Function Call Evaluation

A Python framework for evaluating multi turn LLM conversations, tool selection, function arguments, response quality, and error handling.

## Project Overview

This project demonstrates how AI assistants can use structured tools such as email, calendar, maps, and cloud storage to complete user requests.

The framework evaluates whether the assistant:

Chooses the correct tool

Uses the correct function

Provides all required arguments

Maintains context across multiple turns

Handles missing or invalid information

Responds correctly after receiving tool results

Produces a clear and natural final response

## Key Features

Multi turn conversation evaluation

JSON based function schemas

Tool selection validation

Argument completeness checks

Error handling scenarios

Correction turn evaluation

Structured response validation

Synthetic training data generation
